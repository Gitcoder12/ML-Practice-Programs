# Agent Instructions — ML-Practice-Programs

Read README.md, CONTRIBUTING.md and FEATURE_UPGRADE_PLAN.md before editing.

- Treat this as an educational repository; prioritise clarity over abstraction.
- Preserve mathematical correctness and show the derivation behind new code.
- Add deterministic tests and hand-checkable toy examples.
- Do not introduce hidden reliance on large datasets or heavyweight frameworks.
- State tolerances when comparing to reference libraries.
- Never invent benchmark numbers or test outcomes.
- Work on a branch and open a PR; do not merge autonomously.
