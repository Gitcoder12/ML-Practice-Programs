# ML-Practice-Programs — Company and Team Fit

Matches reflect learning and technical-skill relevance, not claims of company use or endorsement.

## Project thesis

A learning repository with small NumPy implementations of basic machine-learning algorithms so students can see how the maths works under the hood.

## Hugging Face

**Relevant public areas:** Open-source ML education and model tooling.

**Potential roles:** ML Engineer, Research Engineer, Applied Scientist, Developer Educator or Software Engineer.

**Evidence:** Compact Python/NumPy implementations including linear regression, k-nearest neighbours and Gaussian Naive Bayes. The repository is educational and should prioritise mathematical clarity, deterministic examples and comparison with trusted reference implementations over production packaging.
