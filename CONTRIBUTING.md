# Contributing to ML-Practice-Programs

Add a new algorithm? Follow this pattern:

1. Create `programs/your_algorithm.py`
2. Implement from scratch — no sklearn for core logic
3. Include a `if __name__ == "__main__":` block with a working example
4. Add time/space complexity as a comment at the top
5. Update README table with your addition
